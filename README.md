# K-Buy

A second-hand goods ecommerce platform powered by **Shopify** (backend) and **Next.js** (frontend).

## Getting Started

### Prerequisites

- Node.js 18+
- npm

### Installation

```bash
npm install
```

### Development

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build

```bash
npm run build
```

### Production

```bash
npm start
```

### Formatting

```bash
npm run format
```
